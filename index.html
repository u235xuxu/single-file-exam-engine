题库 → 一个 HTML 文件

双击就考。不装东西，不连网，不依赖任何服务。

整理了两个月的资料，翻开觉得自己会了，考场上发现不会。
「看过」和「答对」之间，差的是做一遍。这个工具就是让「做一遍」不再需要先写一遍网页。

▶ 直接试考（10 道示例题）

它做什么

python3 build.py bank.yaml
→ bank.html
  • 题写进 YAML / JSON，纯文本，能进 git、能 diff
  • 界面由引擎负责，一次写好无限复用
  • 产物是单个自包含 HTML——离线、可邮件发、可放 U 盘

支持

  • 五种题型：单选 / 多选 / 判断 / 填空 / 简答
  • 即时判分、逐题解析、计时、进度条
  • 填空智能匹配（忽略空格标点、百分号按数值比）
  • 简答按关键词命中率判定
  • 零第三方依赖（Python 标准库即可）

边界

  • 不防作弊——答案在源码里，F12 可见。单文件离线的代价
  • 不做成绩汇总——没有服务端，刷新即失
  • 不做题库编辑器——题在文本文件里改，这是故意的
